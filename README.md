B.Com Power BI Major Project – Sales Dashboard

Welcome to the B.Com Power BI Major Project repository! This project focuses on analyzing sales data using Microsoft Power BI to understand sales performance and generate meaningful business insights through an interactive dashboard.

📂 Project Directory

* 📂 Major-Project: Contains the complete project documentation and the full PDF report (PowerBI-Major-Project-Sales-Dashboard.pdf).

📊 Key Highlights

* Interactive Power BI Sales Dashboard
* Total Sales analysis
* Total Orders analysis
* Total Customers analysis
* Total Products analysis
* Region-wise sales analysis
* Category-wise sales analysis
* Product-wise performance analysis
* Order date and sales trend analysis
* Interactive filters and slicers
* KPI-based business performance analysis

🎯 Project Objective

The main objective of this project is to analyze sales data and convert raw data into meaningful visual insights using Microsoft Power BI. The dashboard helps understand sales trends, customer behavior, product performance, and regional sales performance.

🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Power Query
* DAX
* Data Cleaning
* Data Analysis
* Data Visualization

📈 Project Outcome

The Power BI dashboard provides an interactive and easy-to-understand view of sales performance. It helps identify important trends, compare different business segments, and understand key sales metrics for better data-driven decision-making.
